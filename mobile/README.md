# 🚀 Overview

Quran Installer is an elegant Android application built with Flutter that makes downloading Holy Quran recitations incredibly simple.

Choose from hundreds of famous reciters, download the complete Mushaf or individual Surahs, monitor download progress, and organize your Quran library effortlessly.

Designed with a clean interface, smooth animations, and excellent performance.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/MOZA-18/Quran-Installer.git
```

Navigate to the mobile project

```bash
cd Quran-Installer/mobile
```

Install dependencies

```bash
flutter pub get
```

Run the application

```bash
flutter run
```
